SysBot.NET for the Dudes & Dudettes

An advanced .NET automation framework powering remote Nintendo Switch console control, automated Pokémon distribution, and Discord queue management via sys-botbase.

Download Latest Release Join Support Discord

Core Capabilities

Everything required to manage automated Nintendo Switch bots

WinForms GUI Launcher

Simple and intuitive desktop interface to configure, monitor, start, and stop individual Pokémon bots with real-time logging and JSON config saving.

Discord Integration

Remotely command and control bot queues through Discord. Set up role-based permissions, automated trade queues, and custom request messaging.

PKHeX & ALM Power

Seamlessly powered by PKHeX and Auto-Legality Mod (ALM) for automated Pokémon legal template validation and generation on the fly.

sys-botbase Client

Asynchronous and synchronous networking core capable of sending gamepad inputs and reading/writing console memory over LAN.

Repository Architecture

Modular .NET 9 solution structure breakdown:

SysBot.Base

Core low-level networking and connection logic for interacting directly with sys-botbase.

SysBot.Pokemon

Game logic layer implementing Pokémon trade sequences and console actions.

SysBot.Pokemon.WinForms

The primary graphical user interface executable for bot host operators.

SysBot.Pokemon.Discord

Discord bot service layer built on Discord.Net for processing user queue requests.
