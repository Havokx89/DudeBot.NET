DudeBot.NET

An enhanced .NET automation framework powering remote Nintendo Switch console control, automated Pokémon distribution, and Discord queue management.

Download Latest Build 💬 Live Demo & Discord GitHub Repository

Core Capabilities

WinForms GUI Launcher

Intuitive desktop interface to configure, monitor, start, and stop individual Pokémon bots with real-time logging and JSON configuration control.

Discord Integration

Remotely command and control trade queues via Discord with role-based permissions, automated queueing, and custom request messaging.

PKHeX & ALM Power

Seamlessly integrated with PKHeX and Auto-Legality Mod (ALM) for automated Pokémon legal template validation and on-the-fly generation.

sys-botbase Client

High-performance asynchronous/synchronous networking core designed to send gamepad inputs and read/write console memory over LAN.
