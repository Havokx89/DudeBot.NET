Privacy Policy for DudeBot.NET

Last Updated: August 12, 2026

This Privacy Policy describes how DudeBot.NET ("we", "us", or "our"), operated and maintained by Havokx89, collects, uses, stores, and protects user information when you interact with our Discord bot service.

1. Information We Collect

To function properly and provide automated Nintendo Switch Pokémon distribution and queue management features, DudeBot.NET processes the following minimal data provided via the Discord API and user command inputs:

  • Discord Account Data: User IDs (Snowflakes), Usernames, display names, and User role IDs (for access control and permissions).
  • In-Game / Bot Interaction Data: Submitted trade data (e.g., Pokémon files/templates, trade codes, requested items), In-Game Name (IGN), and Nintendo Switch Trainer Data.
  • Operational Logs: Bot command logs (command inputs, execution results, error reports).
Note: DudeBot.NET does not collect or store personal private messages (DMs), server chat logs outside of command triggers, passwords, or personal financial information.

2. How We Use Your Information

We process and use the collected data strictly for operational purposes, including:

  • Processing trade and distribution requests in real-time.
  • Managing queue positions, cooldown timers, and command permissions.
  • Debugging technical issues and preventing command abuse or spam.
  • Ensuring compliance with Discord's Terms of Service and bot community guidelines.

3. Data Storage and Retention

  • Temporary Storage: Trade queue requests and active session data are held temporarily in local memory and local configuration/log files on the host machine running the bot instance.
  • Log Retention: Command and error logs are periodically cleared or overwritten based on the host configuration.
  • No Third-Party Data Selling: We do not sell, rent, monetize, or trade any collected user data to third parties.

4. Third-Party Services & Dependencies

DudeBot.NET interacts with third-party libraries and APIs to function, including:

  • Discord API — Used to receive commands and communicate within servers.
  • Open-Source Libraries: (e.g., Discord.Net, PKHeX, Auto-Legality Mod) process data locally during trade file parsing and legality checks.

5. Your Data Rights & Deletion Requests

You have rights regarding your data:

  • Data Access / Inquiries: You can request information about what data (if any) is currently stored in connection to your Discord User ID.
  • Data Deletion: To request the deletion of any stored logs or queue history associated with your Discord account, contact the lead developer.

Contact for Data Requests:

  • Email: dudebot@mailfence.com
  • GitHub Repository: Havokx89/DudeBot.NET
  • Repository Owner: @Havokx89

6. Security

We apply reasonable security controls and standard access restrictions to safeguard bot configuration files, local logs, and hosting environments from unauthorized access. However, no digital transmission or local storage is 100% secure.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any updates will be pushed directly to the official project repository at https://github.com/Havokx89/DudeBot.NET. Your continued use of the bot after any changes signifies your acceptance of the updated policy.
